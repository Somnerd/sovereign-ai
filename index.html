01. Sliding-Window SSE Rehydration

Standard AI gateways buffer entire streaming responses to scan for PII, completely wrecking Time-To-First-Token (TTFT). IronWarden maintains a bounded sliding-window token buffer that inspects arbitrary chunk boundaries using SIMD Aho-Corasick, emitting safe tokens immediately with zero-copy slices.

  • ✔ Zero stream buffering pauses
  • ✔ Sub-millisecond end-to-end token delivery
  • ✔ Homoglyph & zero-width character evasion defense

02. Cryptographic HMAC-SHA256 Audit Chaining

Under the EU AI Act, logging to standard syslog or cloud dashboards is legally non-repudiable. IronWarden seals every prompt and response into an immutable HMAC-SHA256 Merkle chain. If an auditor asks whether customer PII left your VPC, you have mathematical proof of data integrity.

  • ✔ Tamper-proof cryptographic ledger
  • ✔ 100% on-premises / VPC data residency
  • ✔ Zero phone-home telemetry
